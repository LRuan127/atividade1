##  Como executar os códigos

Cada questão está em uma pasta separada.
Para executar, entre na pasta desejada e compile usando o comando:

```bash
g++ main.cpp -o programa
./programa
```

 Em algumas questões (como a 1b e 1c), existem arquivos `.cpp` e `.hpp`, então use:

```bash
g++ main.cpp conta.cpp -o programa
./programa
```

ou

```bash
g++ main.cpp contas.cpp conta.cpp -o programa
./programa
```
